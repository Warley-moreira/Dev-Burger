## 📖 Sobre o projeto

O **DevBurger** é uma aplicação web desenvolvida para praticar os fundamentos do desenvolvimento Front-end utilizando **HTML**, **CSS** e **JavaScript**.

O projeto simula um cardápio de hamburgueria, permitindo interações dinâmicas por meio da manipulação do DOM e de métodos modernos do JavaScript.

## 🚀 Demonstração

🔗 **Projeto Online:**
https://warley-moreira.github.io/Dev-Burger/

## ✨ Funcionalidades

- 🍔 Exibição dos produtos
- 🌱 Filtro de produtos veganos
- 💰 Aplicação de descontos
- 🧮 Cálculo do valor total dos produtos
- 📱 Interface responsiva

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript (ES6+)
